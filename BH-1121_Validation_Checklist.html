2. Structural Fixes Applied

Critical — Duplicate Relationship Name

Both Contact__c and AAR_Record__c on Commercialization__c had relationshipName: Commercialization_Activities. This is a deploy-blocking conflict (Salesforce enforces unique relationship names per object). Fixed: AAR_Record__c now uses relationshipName: Commercializations.

Medium — Misplaced Layout File

objects/AAR_Recognition__c/layouts/ is not a valid SFDX source format path for layouts. File moved to force-app/main/default/layouts/ and deployed. Old file still on disk — must be deleted manually then staged with git rm.
